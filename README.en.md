# 🤰 APP Materna

**An informational mobile app about pregnancy and motherhood, with an illustrated magazine and a myths-and-facts quiz, built in Flutter with FlutterFlow.**

A team project built in 2024 during the Computer Science program at UNISAGRADO.

---

## 🎯 Goal

Pregnancy comes with many popular myths, such as "a pregnant woman has to eat for two" or "heartburn means a hairy baby", which can cause anxiety or lead to poor health choices. APP Materna was created to bring **accessible, reliable information** to pregnant women and their families in a light, interactive way:

- a **magazine** with illustrated content on topics such as breastfeeding;
- a **true-or-false quiz** that debunks common pregnancy myths and explains the correct answer to each one.

---

## ✨ Features

- **Main menu** with access to the Magazine, the Quiz, and the Credits.
- **Magazine:** 5 pages of illustrated content, browsed in sequence.
- **Myths-and-facts quiz:** 24 questions, each with **TRUE** or **FALSE** options, followed by an answer screen with the explanation. Sample questions:
  - *Does a pregnant woman have to eat for two?*
  - *Will women who have heartburn during pregnancy have hairy babies?*
  - *If a pregnant woman does not satisfy her food cravings, will the baby be born with a problem?*
  - *Are iron and folic acid essential nutrients during pregnancy, so much so that the Brazilian government has offered food fortification since 2004?*
- **Completion screen** at the end of the quiz, inviting the user to read the magazine.
- **Credits** with the development team.

The app content is in Portuguese.

---

## 🛠️ Tech stack

- **Flutter / Dart** (SDK ≥ 3.0)
- **FlutterFlow**: visual screen building, with the Flutter code exported to this repository
- **go_router**: navigation between screens
- **provider**: app state
- **google_fonts**, **flutter_animate**, **font_awesome_flutter**: interface

The project builds for **Android**, **iOS**, and **Web**.

---

## ▶️ Running it

Prerequisite: the [Flutter SDK](https://docs.flutter.dev/get-started/install) installed.

```bash
git clone https://github.com/pedromcd/appMaterna.git
cd appMaterna
git checkout flutterflow    # branch with the app code
flutter pub get
flutter run                 # on an emulator, a connected device, or Chrome (-d chrome)
```

├── quiz_pages/               # Quiz: quiz1 … quiz24, answer screens (quizN_resp), and final screen (fimdo_quiz)

## 💡 Takeaways

- **Cross-platform mobile** development with Flutter from a single codebase.
- Using a **low-code** tool (FlutterFlow) to prototype quickly and then work with the generated Flutter code.
- Organizing educational content into a simple navigation flow for a non-technical audience.
